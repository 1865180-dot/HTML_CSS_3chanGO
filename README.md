# コードで進め！（HTML_CSS_3chanGO）

さんちゃんと進む、HTML・CSS のステージ攻略ゲームです。コードを書きかえると、ゲームの世界が変わります。

- 中学校 技術・家庭科（技術分野）「情報の技術」向けの教材です。
- 全6ステージ（チュートリアル＋5ステージ）。2時間の授業で使う想定です（1時間目：ステージ0〜2、2時間目：ステージ3〜5）。
- 学べること：タグ、class、`left`／`bottom`、CSSの数値と色、コメント、`display`、`opacity`、まちがい直し（デバッグ）。

## 遊び方

`index.html` をブラウザで開くだけで動きます（1ファイルで完結）。GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチを選んでください。

- 左がゲーム画面、右がHTML／CSSのエディタです。コードを書きかえて「反映して遊ぶ」をおします。
- 操作：← → で移動、スペースでジャンプ、R でやり直し。
- コードと記録は、その端末のブラウザに自動で保存されます。
