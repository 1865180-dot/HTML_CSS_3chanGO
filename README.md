# さんちゃん Go（HTML_CSS_3chanGO）

さんちゃんと進む、HTML・CSS・JavaScript のステージ攻略ゲームです。コードを書きかえると、ゲームの世界が変わります。

- 中学校 技術・家庭科（技術分野）「情報の技術」向けの教材です。
- 全6ステージ（チュートリアル＋5ステージ）と、全クリア後に遊べるおまけの「激ムズコース（EX）」。2時間の授業で使う想定です（1時間目：ステージ0〜2、2時間目：ステージ3〜5）。
- スタート画面で「スタート」をおすと予告編（`sanchan_pv.mp4`）が流れます。スキップできます。
- 学べること：タグ、class、`left`／`bottom`、CSSの色と大きさ、コメント、`display`、`opacity`、まちがい直し（デバッグ）。HTML（何があるか）・CSS（見た目）・JavaScript（動き）の役割のちがい。

## 遊び方

`index.html` をブラウザで開くと動きます。予告編の動画 `sanchan_pv.mp4` は、`index.html` と同じ場所に置いてください。GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチを選んでください。

- 左がゲーム画面、右がHTML／CSS／JavaScriptのエディタです。コードを書きかえて「反映して遊ぶ」をおします。
- 操作：← → で移動、スペースでジャンプ、R でやり直し。
- コードと記録は、その端末のブラウザに自動で保存されます。
